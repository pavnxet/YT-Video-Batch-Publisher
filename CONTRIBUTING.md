# 🤝 Contributing

Thanks for wanting to help. This is a small, deliberately dependency-free project,
so contributing is mostly about keeping it that way.

## 🐞 Reporting a bug

[Open an issue](https://github.com/pavnxet/YT-Video-Batch-Publisher/issues/new/choose)
and include:

1. **What you expected** and **what actually happened**.
2. **Steps to reproduce** — as few as possible.
3. **Your browser and version** (e.g. Chrome 130, Firefox 132).
4. **The popup log** — the list of videos and outcomes shown after a run.
5. **Console output**, with *Debug logging* turned on in Settings.

A screenshot of the Studio page is very helpful, because this extension depends on
YouTube's markup and small layout differences matter.

## 💡 Suggesting a feature

Open an issue first, before writing code. It is much easier to agree on an approach
in a paragraph than in a pull request.

## 🛠️ Setting up

```bash
git clone https://github.com/pavnxet/YT-Video-Batch-Publisher.git
cd YT-Video-Batch-Publisher
npm install
npm run build
npm test
```

Load `dist/chrome` (or `dist/firefox`) as described in the
[installation guide](https://pavnxet.github.io/YT-Video-Batch-Publisher/install.html).

## ✅ Before you open a pull request

```bash
npm run ci
```

That runs the build, the manifest/bundle validator and the full test suite. All
three must pass.

## 📐 Conventions

- **No runtime dependencies.** The extension ships as plain JavaScript. Dev
  dependencies for tooling and tests are fine; anything that ends up in `dist/`
  is not.
- **One source tree.** Edit files under `src/`. Never edit `dist/` — it is
  generated by `npm run build` and is gitignored.
- **Selectors belong in `src/core/selectors.js`**, as an ordered fallback list.
  Do not scatter query selectors through the engines.
- **Match by label, not by position.** Index-based lookup breaks silently when
  YouTube reorders something.
- **Everything async takes an `AbortSignal`.** A run must be cancellable between
  any two steps.
- **Add a test.** `node:test` + jsdom. If you are fixing a bug, write the test
  that reproduces it first.
- **Style.** Two-space indent, single quotes, semicolons, `async`/`await` over raw
  promise chains. Keep comments about *why*, not *what*.

## 🗂️ Where things live

| I want to change… | Edit |
|---|---|
| How a draft is published | `src/core/publisher.js` |
| How playlist sorting works | `src/core/sorter.js` |
| A YouTube selector | `src/core/selectors.js` |
| A setting | `src/core/settings.js` + `src/options/` |
| The popup | `src/popup/` |
| The settings page | `src/options/` |
| The message contract | `src/core/messaging.js` |
| The documentation site | `docs/` |
