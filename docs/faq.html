Troubleshooting & FAQ

The problems people hit most often, and what to do about them.

Common problems

"Manifest file is missing or unreadable"

You are pointing the browser at a folder that has no manifest.json. This almost always means one of two things:

  • You selected the repository root. The source tree keeps its manifests in manifests/ and builds the loadable extension into dist/ — the top level of the repo is not loadable. Select dist/chrome instead, or download a release build.
  • You selected the zip, or the folder above the extracted files. Extract the zip first, then select the folder that directly contains manifest.json.
The popup says "Not on Studio"

The extension only activates on studio.youtube.com. Check that:

  • You are on the Studio content page, not youtube.com or a watch page.
  • You are signed in to the right channel — Studio for a brand account still lives on the same hostname.
  • You have reloaded the page since installing or updating the extension.
It found fewer drafts than I expected

The extension publishes exactly the rows visible on the page. If the list is filtered, or you have not scrolled, the rest are not in the page yet.

Fix: clear the filter, or scroll the list until all the drafts you want are on screen, then press Rescan in the popup.

A video failed with "Edit-draft button not found"

Usually a rendering race. Raise Action delay and Step timeout in Settings, and give Retries per video a value of 1 or 2.

If it is always the same video, that video may need attention in Studio — for example a missing required field — before it can be published at all.

The batch stopped halfway through

Check the log in the popup — it lists every video and its outcome. A video reported as error is one that failed; with Continue on error switched on, the rest will still have gone through.

Nothing is ever half-published: a video is either saved with the visibility you chose, or untouched.

It is slower than I would like

Lower Action delay and Step timeout. There is a floor, though: the extension deliberately waits for each page to settle, because moving too fast is what causes failed saves.

YouTube changed their interface and it broke

Studio's markup is not a public API. Every selector lives in one file, src/core/selectors.js, with ordered fallbacks — adding the new selector there is usually a one-line fix.

Please open an issue with a screenshot and we will get it updated.

Questions

How many videos can it publish at once?

As many drafts as are visible on the page. There is no hard limit in the extension, but smaller batches are easier to review — filtering to a subset is a good habit.

Can I undo a publish?

Yes. Change the visibility back in YouTube Studio, or delete the video. Use Dry run first if you are unsure what a run would do.

Does it collect any data?

No. There is no server, no analytics and no account. The only network traffic is the Studio page talking to YouTube, exactly as it would without the extension.

Will it publish videos that are not drafts?

No. It only touches rows that expose an edit-draft control, which is what distinguishes a draft from an already-published video.

Does it work with brand accounts?

Yes — Studio uses the same hostname for brand accounts, so nothing changes.

Why do I have to build it myself?

You don't have to — the releases page has ready-made zips for both browsers. Building from source is only for people who want to change the code; it takes a few seconds and needs Node.js 20+. See Installation.

Reporting a bug

Before you file it, please:

  1. Turn on Debug logging in Settings.
  2. Reproduce the problem with the Studio tab's browser console open.
  3. Note what you saw — the popup's log, the console output, and roughly how many drafts were on the page.
  4. Open an issue with those details and your browser version.
