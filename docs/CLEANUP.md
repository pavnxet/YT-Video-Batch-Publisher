# Cleanup — what was deleted and why

The original repository shipped 28 tracked files plus a committed
`node_modules/`. Version 2.0 removes everything that was not source, was
duplicated, or was already stale.

## Deleted outright

| Path | Size | Why |
|---|---:|---|
| `node_modules/` | 46.6 MB (165 packages) | Installed dependencies must never be committed. The extension has no runtime dependencies at all; only `jsdom` (dev, for tests) is declared now. |
| `package-lock.json` | 83 KB | Lockfile for a single devDependency that is no longer used (`addons-linter`). Regenerated by `npm install` for the new devDependency. |
| `_metadata/computed_hashes.json` | 696 B | Chrome Web Store per-package signature. Meaningless outside a published CRX, and stale the moment any file changes. |
| `_metadata/verified_contents.json` | 2.3 KB | Same — store signing metadata. |
| `_metadata/readme.md` | 1 B | Empty file. |
| `icons/readme.md` | 1 B | Empty file. |
| `firefox/script.js` | 12.7 KB | Byte-identical copy of `script.js`. Two copies with no build step meant they would (and did) drift. Now generated into `dist/firefox/`. |
| `firefox/popup.js` | 227 B | Same — identical copy. |
| `firefox/popup.html` | 3.0 KB | Same — identical copy. |
| `firefox/background.js` | 713 B | Firefox flavour of the background script; now generated from one `src/background/` source with the right manifest. |
| `firefox/manifest.json` | 852 B | Now generated from `manifests/firefox.json`. |
| `firefox/icons/*` (5 files) | ~31 KB | Duplicate icon set — and `firefox/icons/icon128.png` (21.8 KB) was **not the same image** as `icons/icon128.png` (73.1 KB), so the two browsers shipped different icons. One shared `icons/` set is copied to both targets. |
| `.github/workflows/super-linter.yml` | 1.3 KB | `super-linter@v4` is end-of-life and, with `VALIDATE_ALL_CODEBASE: false` on a repo with no other linter config, checked essentially nothing. Replaced by `ci.yml`, which builds, validates and tests. |

## Replaced / reorganized (content preserved)

| v1.1 | v2.0 |
|---|---|
| `script.js` (12.7 KB, everything in one IIFE) | `src/core/{dom,selectors,settings,messaging,publisher,sorter}.js` + `src/content/content.js` |
| `background.js` | `src/background/service-worker.js` |
| `popup.html` / `popup.js` | `src/popup/{popup.html,popup.css,popup.js}` (redesigned) |
| — | `src/options/` (new settings page) |
| — | `src/ui/theme.css` (shared design tokens, dark mode) |
| `manifest.json` | `manifests/chrome.json` + `manifests/firefox.json` |
| `README.md` | rewritten |
| — | `LICENSE` (MIT), `CHANGELOG.md`, `.gitignore`, `docs/` |

## Kept unchanged

* `icons/icon16.png`, `icon32.png`, `icon48.png`, `icon128.png` — the real icon
  set, now shared by both browser targets.
* `firefox/icons/icon.png` — kept as `icons/icon.png` (the extension's
  general-purpose icon referenced by the popup header).

## Net effect

| | v1.1 | v2.0 |
|---|---:|---:|
| Tracked files (excl. `node_modules`) | 28 | 45 |
| Committed dependency bytes | 46.6 MB | 0 |
| Source copies of the same logic | 2 | 1 |
| Build outputs generated | 0 | 2 (`dist/chrome`, `dist/firefox`) |
