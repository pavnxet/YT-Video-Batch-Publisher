Installation

The extension is distributed as source, so the first step is to build it. It takes about ten seconds and produces ready-to-load folders for both browsers.

1. Get the code and build

You will need Node.js 20 or newer. Nothing else.

git clone https://github.com/pavnxet/YT-Video-Batch-Publisher.git
cd YT-Video-Batch-Publisher
npm install
npm run build

That writes two folders:

FolderUse it for
dist/chromeChrome, Edge, Brave, Opera, Vivaldi
dist/firefoxFirefox 115 and newer
📦 Why a build step?

One source tree generates both browser packages. Without it, the Chrome and Firefox copies drift apart over time — a class of bug that is invisible until someone notices a feature is missing in one browser.

2a. Load it in Chrome, Edge, Brave or Opera

  1. Open the extensions page Go to chrome://extensions/ (or edge://extensions/, brave://extensions/).
  2. Turn on Developer mode The toggle sits in the top-right corner.
  3. Click "Load unpacked" It appears in the toolbar once Developer mode is on.
  4. Select the dist/chrome folder Not the repository root — the manifest lives inside dist/chrome.
  5. Pin it Click the puzzle-piece icon in the toolbar and pin YouTube Video Batch Publisher so it is always one click away.

2b. Load it in Firefox

  1. Open the debugging page Go to about:debugging#/runtime/this-firefox.
  2. Click "Load Temporary Add-on…"
  3. Select dist/firefox/manifest.json Pick the manifest file itself, not the folder.
⚠️ Temporary means temporary

A temporary add-on disappears when Firefox restarts. For a permanent install, sign the build:

npx web-ext build -s dist/firefox

3. Confirm it is working

Open YouTube Studio and click the extension icon. You should see a green YouTube Studio badge and a count of the drafts it can find on the page.

If it says "Not on Studio", you are on a different tab or a different hostname — see Troubleshooting.

Permissions, explained

The extension asks for the minimum it needs, and nothing more.

PermissionWhy
storageRemembers your settings in chrome.storage.sync.
activeTabLets the popup talk to the tab you are looking at.
scriptingInjects the automation script if the page was already open when you installed.
host: studio.youtube.comScoped to YouTube Studio only. It has no access to any other site.

Updating

git pull
npm install
npm run build

Then click the reload ⟳ button on the extension's card in chrome://extensions/.
