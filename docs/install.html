Installation

Two ways in: download a ready-made build, or build it from source. The first takes a minute and needs no tools at all.

⚠️ Don't load the repository root

The source tree has no manifest.json at the top level — the loadable extension is generated into dist/. If you point your browser at the repository folder you will see "Manifest file is missing or unreadable". Use a release build below, or run the build yourself.

Option A — download a ready-made build

No Node.js, no build step. Pick your browser:

🌐

Chrome · Edge · Brave · Opera

Download the Chrome zip →

🦊

Firefox 115+

Download the Firefox zip →

Chrome, Edge, Brave or Opera

  1. Download and extract Download the Chrome zip and extract it to a folder you will keep — for example C:\Extensions\yt-batch-publisher. Chrome cannot load an extension from inside a .zip, so extracting is not optional.
  2. Open the extensions page Go to chrome://extensions/ — or edge://extensions/, brave://extensions/, opera://extensions.
  3. Turn on Developer mode The toggle sits in the top-right corner.
  4. Click "Load unpacked" It appears in the toolbar once Developer mode is on.
  5. Select the extracted folder Pick the folder that contains manifest.json — not its parent, and not the zip.
  6. Pin it Click the puzzle-piece icon in the toolbar and pin YouTube Video Batch Publisher so it is always one click away.
💡 Keep the folder where it is

If you move or rename the extracted folder later, the extension will be disabled until you reload it from the extensions page. Put it somewhere permanent.

Firefox

  1. Download and extract the Firefox zip.
  2. Open the debugging page Go to about:debugging#/runtime/this-firefox.
  3. Click "Load Temporary Add-on…"
  4. Select the extracted manifest.json Pick the manifest file itself, not the folder.
⚠️ Temporary means temporary

A temporary add-on disappears when Firefox restarts. For a permanent install, sign the extracted folder:

npx web-ext build -s <extracted-folder>

Option B — build from source

You will need Node.js 20 or newer. Nothing else.

git clone https://github.com/pavnxet/YT-Video-Batch-Publisher.git
cd YT-Video-Batch-Publisher
npm install
npm run build

That writes two folders:

FolderUse it for
dist/chromeChrome, Edge, Brave, Opera, Vivaldi
dist/firefoxFirefox 115 and newer

Load dist/chrome using the same steps as above.

📦 Why is there a build step?

One source tree generates both browser packages. Without it, the Chrome and Firefox copies drift apart over time — a class of bug that stays invisible until someone notices a feature is missing in one browser.

Check it is working

Open YouTube Studio and click the extension icon. You should see a green YouTube Studio badge and a count of the drafts it can find on the page.

If it says "Not on Studio", you are on a different tab or a different hostname — see Troubleshooting.

Permissions, explained

The extension asks for the minimum it needs, and nothing more.

PermissionWhy
storageRemembers your settings in chrome.storage.sync.
activeTabLets the popup talk to the tab you are looking at.
scriptingInjects the automation script if the page was already open when you installed.
host: studio.youtube.comScoped to YouTube Studio only. It has no access to any other site.

Updating

From a release build: download the newer zip, extract it over the same folder, then click the reload ⟳ button on the extension's card in chrome://extensions/.

From source:

git pull
npm install
npm run build

Then reload the extension the same way.
